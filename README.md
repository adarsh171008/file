CYBER-X Landing Page

A futuristic cyborg-themed landing page built using HTML, CSS, and JavaScript. This project showcases a modern cyberpunk-inspired UI with responsive design, interactive elements, and smooth user experience.

Features

- Futuristic Cyborg/Cyberpunk Design
- Fully Responsive Layout
- Interactive Typing Animation
- Smooth Navigation
- Modern Glassmorphism Cards
- Mobile-Friendly Interface
- Clean and Organized Code

Technologies Used

- HTML5
- CSS3
- JavaScript

Sections

1. Hero Section
2. Features Section
3. About Section
4. Statistics Dashboard
5. Contact Section

Project Objective

The objective of this project is to create a visually appealing and responsive landing page inspired by futuristic cyborg technology, artificial intelligence, and human-machine integration.

Installation

1. Clone the repository:
   
   git clone <repository-url>

2. Open the project folder.

3. Launch "index.html" in your browser.
